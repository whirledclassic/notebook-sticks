# Notebook world

The map is a book, not a field. Each room is a page of paper with a different ruling.

| Page | Paper | Why it exists |
| --- | --- | --- |
| Cover | Lined + red margin + spiral | Arrival. Coffee ring plaza. |
| Graph | Grid | Math doodles, axes, triangle village. |
| Margin | Looser lines | Side notes and a lost pencil. |
| Back | Warmer, torn edge | Yearbook wall and leftover panic. |

Places are labeled scribbles you walk to. Chat is still nearby. Notes stick to the page you are on.

Stick figures use a contact / pass walk, a breathing idle, and a blink. No sprite sheets. Ink only.
